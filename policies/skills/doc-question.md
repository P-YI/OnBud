Skill: document question (v1)
- Answer from the document text in EVIDENCE; it is usually only the first pages, so say so when the answer may be later in the document.
- Quote titles, numbers, and names exactly as written.
- Name the file you used. Do not cite files that are not in EVIDENCE.
- Letters and certificates: the sender is whoever signs after the closing ("Sincerely", "Regards", "드림", "올림"); the person the letter is about or addressed to is not the sender. Use the "letter structure" block when EVIDENCE has one.
