# OnBud 0.2.1

A small update to 0.2.0 (2026-11-09). Apple silicon, macOS 26 or later, Apple Intelligence on.

## Changes
- **Architecture diagram** in the README, below "What you get": entry points, the controller (safety, then the
  decision), the 13 skills, the three models and the code ladder, your approval, execution, and the checks that
  feed back. Light and dark versions follow GitHub's theme (`docs/assets/architecture-{light,dark}.svg`).
- The app reports version 0.2.1. No change to the controller, skills or settings.

## Upgrade
Homebrew: `brew upgrade --cask onbud`. DMG: replace OnBud.app with the one below. Upgrading from 0.1.0 (then
called OpenAFM): see the 0.2.0 release notes.
